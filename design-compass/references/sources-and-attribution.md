# Source routing and attribution

Read only the sections relevant to the current task. Links are research starting points, not permission to reproduce hosted work.

## Evidence ladder

Prefer the highest available rung that answers the question:

1. A live product, first-party design system, or official documentation for behavior and implementation facts.
2. A real-product screen or flow archive for comparative product evidence.
3. A curated gallery for composition, art direction, and trend discovery.
4. A moodboard or portfolio network for broad visual exploration.
5. A component demo or prompt library for implementation ideas after the design direction is established.

Open the original product or creator page when a gallery links to it. A screenshot proves only what is visible in that captured state; it does not prove accessibility, responsiveness, conversion performance, or current behavior.

## Real products and flows

Use these for tasks, states, navigation, UX copy, interaction sequences, and responsive product behavior. Access may require an account or subscription; use only what the current session is authorized to view.

| Source | Best used for | Access and evidence note |
|---|---|---|
| Live product and official design system | Current behavior, semantics, content, responsive states, and implementation rules | Strongest evidence; record the exact page and observation date |
| [Mobbin](https://mobbin.com/) | Mobile and web product screens, UI elements, and end-to-end flows | Freemium; deeper search, flows, API, and MCP access may be paid |
| [Refero](https://refero.design/) | Web and iOS screens, flows, UX patterns, UI elements, and AI-oriented research | Public previews plus account-gated material; cite the inspected layer |
| [Page Flows](https://pageflows.com/) | Recorded iOS, Android, and web flows with step annotations | Screenlane now resolves here; some material is trial or subscription gated |
| [Nicelydone](https://nicelydone.club/) | Real SaaS screens, flows, components in context, and copy patterns | Best for shipped B2B and desktop-product conventions; full access is paid |
| [SaaSFrame](https://www.saasframe.io/) | SaaS marketing pages, product flows, emails, and desktop/mobile comparison | Useful for SaaS-specific research; full browsing and Figma files are paid |

## Components, terminology, and implementation

Use these after the page job and design direction are clear. A component library is not evidence that its pattern fits the product.

| Source | Role | Usage note |
|---|---|---|
| [NameThatUI](https://namethatui.com/) | Identify UI terms, nearby alternatives, and platform/API vocabulary | Use the name as a starting point, then verify behavior and accessibility |
| [The Component Gallery](https://component.gallery/) | Compare how public design systems define and name components | Follow links to the first-party design-system guidance |
| [Design System Gallery](https://designsystem.gallery/) | Discover public design systems and their source material | Prefer the linked official system over the directory summary |
| [React Bits](https://reactbits.dev/) | Animated React backgrounds, text effects, and interaction components | Free library currently uses MIT plus Commons Clause; Pro has separate terms |
| [Aceternity UI](https://ui.aceternity.com/) | React, Tailwind CSS, and Motion components and landing-page blocks | Free, Pro, and third-party items may have different licenses |
| [Uiverse](https://uiverse.io/) | Community HTML/CSS UI elements and small interactions | Site states MIT for published UI elements; still inspect quality and accessibility |
| [Origin UI](https://originui.com/) | React and Tailwind application components following shadcn conventions | Personal and commercial use is allowed; demos may not be redistributed or resold |

Check the exact repository, file, component, or product terms at the time of use. Preserve required notices and avoid pasting paid or access-controlled source into a deliverable.

## Source recipes

- **Product UI:** one live product or official system, one or two real-flow archives, and one terminology or design-system source.
- **Landing page:** one live competitor, two curated website sources with different aesthetic biases, and one brand or typography source.
- **Experimental mobile or portfolio:** one conventional usability baseline plus Recent, loadmo.re, MUUUUU.ORG, Awwwards, or Design Spells for craft.
- **Brand or editorial:** one direct creator or brand source, one curated editorial source, and one culturally relevant regional platform.
